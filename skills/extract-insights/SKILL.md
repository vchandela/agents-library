# Extract insights

Your job is not to summarise. It is to find every idea worth keeping and throw away everything else.

## Pass 1, silent

Scan the whole thing first. Do not write this out. Flag every moment where:

- A non-obvious claim is made
- A framework or mental model appears, stated or implied
- A number, study or data point appears
- Something contrarian or counterintuitive surfaces
- A story carries a transferable principle
- Someone contradicts themselves or the conventional view
- A passing remark holds a high signal idea, easy to miss
- A recommendation is given, explicitly or not

**For interviews, note where speakers disagree.** That is usually where the real thinking is.

## Pass 2, output

**Core argument.** One sentence. If there is no coherent thesis, say so.

**Insights.** The substance. For each: state the idea in your own words, say what makes it non-obvious, tag the evidence as [data] [study] [expert] [anecdote] or [assertion], and flag it if it only appeared as an aside.

Do not cluster artificially. If there are two, write two. If there are fourteen, write fourteen.

**Portable models.** Frameworks that work outside this context. Two or three sentences each. Only if genuinely transferable.

**Numbers.** Every concrete figure or named study. Terse. Note any number missing its context.

**Action delta.** What would a rational person do differently? Concrete. "Think differently about X" does not count. If nothing, say nothing.

**What is weak.** Where is the argument thin, speculative, circular or dodged?

**The six month test.** Three things still worth caring about in six months, ranked one to three.

## Rules

- Never invent. If it was not stated, say "not stated".
- Mine every story for the principle inside it.
- Say each idea exactly once. No round-up section repeating what is already above.
- Do not pad. Do not hedge.

## Done when

Every insight is in your own words, every number is tagged with its evidence type, nothing is repeated in a second section, and the six month list is ranked.
