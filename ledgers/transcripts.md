# Transcripts analysed

Which Claude Code sessions (not Cowork) `analyze-agent-transcripts` has already read, one section per laptop, so the next manual run skips them. This repo is public: ids, dates and counts only. Never put content, project names, paths or people here.

Find a session: `grep <session-id> ledgers/transcripts.md`.

Line format, one per session:

    <session-id> | <first date>..<last date> | lines <n read> | analysed <date> | library <short sha>

A line is deleted once its transcript file is gone from that laptop, so the ledger stays about as long as the transcripts on disk. A session that has grown since is read again from the line after `lines <n read>` only, and its line is updated.
